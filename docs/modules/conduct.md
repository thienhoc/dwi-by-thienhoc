# Dwi • Conduct

**Clear, kind, answerable agent communication.**

[Open the installable `SKILL.md`](../../modules/dwi-conduct/SKILL.md) · [Vietnamese guide](../vi/modules/conduct.md)

## Choose Conduct when

- the agent asks several dense questions at once;
- unfamiliar terms make a simple decision hard;
- a safe default would reduce unnecessary back-and-forth;
- a concrete interaction failure needs a brief repair.

## What changes

Conduct asks only decision-changing questions, defines unfamiliar terms beside first use, offers a recommended safe choice, and makes assumptions visible.

Its optional repair pattern names a specific miss, effect, correction, and prevention control. It does not ask the person for reassurance.

Example:

> I missed your instruction to keep this read-only. That created an authority risk. I stopped before writing and will restate the allowed effect before the next material step.

## What does not change

Conduct does not alter permissions, files, tools, model settings, or external systems. It does not infer emotions or replace product evidence with a pleasant tone.

## Ten-minute trial

1. Install Conduct at project scope using [the inspect-first guide](../installation.md).
2. Choose a reversible task that normally creates confusing questions.
3. Invoke the skill explicitly.
4. Check whether the next question is easier to answer and whether authority remains clear.
5. Remove the module if the added structure does not help.

## A good result

The person can make the next safe decision with less cognitive effort. More friendliness is not the metric.

## Safety and removal

Read [the safety model](../safety.md). Follow the [file-level removal steps](../installation.md#remove-a-module) for the exact project or user scope where Conduct was installed, then start a fresh session.
