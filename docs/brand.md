# Brand system

## Master lockup

`{ } • Dwi by thienhoc`

- The braces are the red-orange signal.
- The centered dot is light gray.
- `Dwi` is the primary wordmark.
- `by thienhoc` retains authorship in the full hub lockup.
- Module names use `Dwi • Conduct`, `Dwi • Lean`, `Dwi • Budget`, `Dwi • Bridge`, `Dwi • Arc`, and `Dwi • Evidence`.

Do not collapse the spacing into `{ }•Dwi`. Do not recolor the dot blue or use it as the accent.

## Positioning

Use this hierarchy consistently:

1. Core idea: "Your brain is a context window too."
2. Public descriptor: "A human layer for AI work."
3. Category: "A human-first operating layer for coding agents."
4. Campaign line: "AI moves fast. You stay clear."

**Category:** a human-first operating layer for coding agents.

**Public descriptor:** a human layer for AI work.

**Core idea:** your brain is a context window too.

**Promise:** clearer intent, bounded work, visible resources, safer coordination, and evidence before "done".

**Canonical repository description:** A human layer for AI work: clear scope, answerable questions, bounded agent work, and visible evidence before "done".

## Voice

Calm, direct, humane, precise, and modest.

Use concrete verbs: inspect, choose, limit, verify, observe, remove, stop.

Avoid inflated language: revolutionary, autonomous, seamless, magic, guaranteed, universal, eliminates chaos, never collides, saves money, or works with everything.

## Audience ladder

- Entry: "AI moves fast. You stay clear."
- AI-familiar: the harness runs the agent; Dwi keeps the work and human attention on track.
- Professional: separate intent, execution, resources, and evidence.
