# Brand system

## Master lockup

`{ } • Dwi by thienhoc`

- The braces are the red-orange signal.
- The centered dot is light gray.
- `Dwi` is the primary wordmark.
- `by thienhoc` retains authorship in the full hub lockup.
- Module names use `Dwi • Conduct`, `Dwi • Lean`, `Dwi • Budget`, `Dwi • Bridge`, `Dwi • Arc`, and `Dwi • Evidence`.

Do not collapse the spacing into `{ }•Dwi`. Do not recolor the dot blue or use it as the accent.

## Positioning

Use this hierarchy consistently:

1. Category: "The Human Layer for AI Agents."
2. Definition: "A modular human layer that helps reduce overplanning, token waste, context loss, and actions taken without clear permission."
3. Core idea: "Your brain is a context window too."
4. Campaign line: "AI moves fast. You stay clear."

**Category:** The Human Layer for AI Agents.

**Product form:** a modular human layer.

**Parts:** six independently installable modules.

**Distribution:** agent-native instructions. Use "Agent Skills" only when a technical explanation of a supported package or discovery path requires it.

**Core idea:** your brain is a context window too.

**Promise:** helps reduce overplanning, token waste, context loss, and actions taken without clear permission.

**Canonical repository description:** A modular human layer that helps reduce overplanning, token waste, context loss, and actions taken without clear permission.

## Voice

Calm, direct, humane, precise, and modest.

Use concrete verbs: inspect, choose, limit, verify, observe, remove, stop.

Avoid inflated language: revolutionary, autonomous, seamless, magic, guaranteed, universal, eliminates chaos, never collides, saves money, or works with everything.

## Audience ladder

- Entry: "The Human Layer for AI Agents."
- AI-familiar: Dwi is a modular human layer, not another AI skill collection.
- Professional: modules shape communication, decisions, coordination, resources, and evidence inside an existing harness.

## Asset rights

The vector brand and architecture sources embed no proprietary font or third-party mark. The approved GitHub social preview is the fixed 1280×640 raster at `assets/social-preview.png`; its ImageGen master hash, normalizer, dimensions, date, and output hash are recorded in `assets/ATTRIBUTION.md`. `assets/social-preview.svg` is only a repository-relative compatibility wrapper around that raster. A future typography or composition change requires a new receipt and human approval.

The external human-layer introduction is [d.wi.works](https://d.wi.works). This repository intentionally contains no website runtime.
