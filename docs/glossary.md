# Plain-language glossary

| Term | Plain meaning |
| --- | --- |
| Coding agent | An AI system that can inspect code, propose changes, and use approved tools |
| AI coding tool (native harness) | A first-party app or command-line tool, such as Codex or Claude Code, that runs an agent and enforces tool permissions |
| Agent Skill | A discoverable instruction folder whose required behavior file is `SKILL.md` |
| Project scope | Installation that affects only one repository |
| User scope | Installation available across the current user's projects |
| Scope | The files, systems, or decisions an action is allowed to affect |
| Writer | The one agent allowed to change a stated mutable scope |
| Root | The Arc role that owns the user outcome, integration, and acceptance |
| Cell | One bounded Arc work unit with a specific question or write scope |
| Cached input | Input the harness explicitly reports as reused; it is not automatically money saved |
| Provenance | Where evidence came from, when, in which environment, and by which method |
| Static evidence | Evidence from files, configuration, structure, or syntax |
| Runtime evidence | Evidence observed while the relevant system is running |
| Human evidence | A decision or judgment only the authorized person can provide |

When a term does not help the next decision, prefer the plain meaning instead.
