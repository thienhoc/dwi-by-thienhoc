# Dwi v0.2.6

Release status: approved for publication

Release type: Unicode and parser-integrity patch

Release date: 2026-07-26

## Summary

Dwi v0.2.6 addresses three valid review findings reported after `v0.2.5` was published. It further hardens Codex metadata validation without changing module bodies, checksums, installed artifact shapes, native permissions, or the explicit-invocation contract.

## Fixed

- Reject non-ASCII whitespace between a mapping key and its colon, including visually ambiguous no-break spaces.
- Reject YAML-forbidden control characters anywhere in metadata, including inside comments.
- Reject lone UTF-16 surrogate code units in source text and in decoded quoted keys or scalar values.
- Preserve valid surrogate pairs and ordinary Unicode content.

## Validation

- Added targeted fixtures for no-break spaces before `interface` and `policy` colons.
- Added control-character fixtures in mapping and scalar comments.
- Added lone high-surrogate and lone low-surrogate escape fixtures.
- Added a positive escaped surrogate-pair fixture.
- Preserved the complete adversarial suite and all seven-module Codex and Claude Code installed-artifact tests.
- Final candidate passed on Node.js 20 and 24 in workflow run `30184890807` before release-gate closure.
