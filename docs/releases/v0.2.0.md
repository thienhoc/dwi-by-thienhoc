# Dwi by thienhoc v0.2.0

Release date: 2026-07-25  
Release commit: the commit resolved by the annotated tag `v0.2.0`.

## Release contents

The `v0.2.0` release publishes seven installable modules:

- `dwi-conduct`
- `dwi-lean`
- `dwi-budget`
- `dwi-bridge`
- `dwi-arc`
- `dwi-evidence`
- `dwi-all-in-one`

All-in-One is an optional composition module. It selects relevant focused lenses when multiple observed problems recur; it does not create a new runtime, authority layer, or permission system.

## Installation and verification

Install from the immutable `v0.2.0` tag. Verify the selected module against `checksums/SHA256SUMS` before installation, keep overwrite protection enabled, and use the exact removal procedure in the installation guide.

Codex and Claude Code records remain bounded evidence. They do not establish universal harness, model, operating-system, shell, or module compatibility.

The static repository validator checks repository contracts and documentation truth. It does not replace runtime evidence or prove behavioral performance.

## Known limitations

- Compatibility observations retain explicit unknowns and bounded scope.
- No universal compatibility, token-savings, or performance claim is made.
- All-in-One remains optional and should be used only when its relevance gate is met.
- Native harness permissions and policy controls remain authoritative.
