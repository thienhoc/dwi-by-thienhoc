# License policy

Wi selected a three-part license boundary for Dwi by thienhoc:

- Code, installable modules, scripts, and operational configuration: Apache License 2.0.
- Documentation and original repository assets: Creative Commons Attribution 4.0 International.
- Project names and source-identifying marks: the separate policy in `TRADEMARKS.md`.

This allows free use, commercial use, and derivative work under the applicable license while preserving attribution and preventing misleading claims of endorsement.

## Why this combination

Apache-2.0 gives code users a permissive copyright grant, an express patent grant, and notice-preservation duties. CC BY 4.0 gives documentation and asset users broad reuse and adaptation rights with attribution. Neither license grants trademark rights.

## Where each license applies

[LICENSES.md](../LICENSES.md) is the path-level authority. The root [LICENSE](../LICENSE) contains Apache-2.0. [LICENSES/CC-BY-4.0.txt](../LICENSES/CC-BY-4.0.txt) contains CC BY 4.0. [NOTICE](../NOTICE) identifies the project and copyright holder.

## Attribution

For CC BY material, a practical credit line is:

> Dwi by thienhoc by Trần Thiện Học — https://d.wi.works — licensed under CC BY 4.0.

Identify modifications when sharing an adaptation. For Apache-2.0 material, retain the license, relevant notices, and modification notices required by that license.

## Brand boundary

Licensed material may be used and modified. A modified distribution should use a distinct primary name unless separate written permission allows use of a Dwi mark. Truthful statements such as "Based on Dwi by thienhoc" remain welcome.

This page explains the selected policy; the license texts control if this summary differs from them. It is not legal advice.
