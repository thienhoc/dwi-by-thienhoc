## Interpretation

`OBSERVED` means the recorded event occurred in a bounded case.

It does not mean:

- every Dwi module was tested;
- every model or harness version behaves the same way;
- user-scope installation was tested;
- every operating system or shell is supported;
- future harness versions will remain compatible;
- All-in-One was included in the `v0.1.0` trial.

A new compatibility statement requires a new evidence record with the exact repository revision, harness version, environment, module, method, result, failures, and remaining unknowns.
