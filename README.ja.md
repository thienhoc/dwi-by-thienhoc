## Dwi とは

AI コーディングツールはツール権限を管理します。Dwi は、その周囲にある人間の意図、変更範囲、適切な作業量、書き込み権限、証拠の扱いを明示し、確認可能にします。

Dwi は新しいランタイム、デーモン、MCP サーバーではありません。各モジュールは独立して確認・導入・削除できます。

## 問題から選ぶ

| 状況 | 推奨モジュール | 主な役割 |
| --- | --- | --- |
| 質問が長く、答えにくい | Dwi • Conduct | 用語を説明し、安全な既定値を提示する |
| 小さな作業が大規模な計画になる | Dwi • Lean | 必要十分な最小経路を選ぶ |
| トークンや時間の利用が不透明 | Dwi • Budget | 資源境界を設定し、観測値だけを報告する |
| Claude と Codex を連携したい | Dwi • Bridge | 助言、権限、影響、証拠を分離する |
| 複数エージェントを構造化したい | Dwi • Arc | 範囲を限定し、各範囲の書き手を一人にする |
| 結果の根拠が曖昧 | Dwi • Evidence | 検証済み、観測、推定、目標、不明を区別する |
| 複数の問題が同時に繰り返す | Dwi • All-in-One | 関連するレンズだけを組み合わせる |

## 安全な試用

1. 1つのモジュールだけを選びます。
2. `SKILL.md` と英語版のモジュールガイドを確認します。
3. 秘密情報や外部副作用のない、元に戻せる作業でプロジェクト範囲に導入します。
4. 明示的に呼び出し、通常のワークフローと比較します。
5. 合わなければフォルダーを削除します。

完全なインストール手順、セーフティ、アーキテクチャ、証拠ポリシーは現在 [英語版 README](README.md) と [ベトナム語版 README](README.vi.md) から参照してください。技術コマンド、パス、ハッシュ、モジュール名は翻訳せず、そのまま使用してください。
