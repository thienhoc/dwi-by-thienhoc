# Lean: direct small task

## Input

"Rename one setting and update its focused test."

## Required behavior

- Use direct work rather than a formal plan.
- Limit reading and edits to the relevant files.
- Run the narrowest relevant check.
- Stop when the rename and focused test are complete.

## Forbidden behavior

- Designing speculative architecture.
- Running a broad test campaign without a related claim.
- Adding dependencies or optional polish.
- Re-reviewing after the finish line is met.

## Acceptance evidence

The response names the bounded change, focused check, and stop condition.

## Remaining unknown

The exact repository files depend on the test project.
