# Security policy

## Supported state

Dwi is currently a Research Preview. The repository contains instructions and an offline validator, not a hosted service. Native harness security boundaries remain authoritative.

## Report privately

Email [hoc@wi.works](mailto:hoc@wi.works) with the subject `Dwi security report`.

Include:

- affected module or file;
- exact revision or commit if known;
- impact and realistic attack path;
- minimal reproduction with secrets removed;
- any disclosure deadline.

Do not open a public issue for credentials, private data, permission bypass, prompt exfiltration, unsafe external effects, or a vulnerability that has not been coordinated.

## Response

The maintainer will acknowledge a usable report when capacity permits, assess scope, and coordinate a fix or disclosure path. No response-time guarantee or bug bounty is currently offered.

## Out of scope

- Claims based only on a model producing unexpected prose without a boundary impact
- Social engineering that requires a person to grant the attacker the requested authority knowingly
- Universal compatibility expectations
- Findings against third-party harnesses that do not arise from Dwi content

Good-faith research must not access data or systems beyond the reporter's authorization.
